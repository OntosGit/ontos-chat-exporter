ONTOS · Локальный инструмент

Сохраняем разговор целиком

Этот просмотрщик читает прямой JSON одного чата или официальный архив ChatGPT, находит разговор и создаёт HTML, в котором все сообщения присутствуют одновременно. Без прокрутки ChatGPT, без сервера, без установки программ.

▤
Перетащи JSON одного чата или ZIP-архив ChatGPT
Можно выбрать прямой JSON из расширения ONTOS или архив conversations*.json
Все данные обрабатываются непосредственно на этом компьютере.

Нет сетевых запросов и внешних библиотек. Если экспорт включает картинки, звук или прикреплённые файлы, HTML показывает ссылки/описания, а не копии бинарных данных. Оригинальный ZIP лучше хранить отдельно.
