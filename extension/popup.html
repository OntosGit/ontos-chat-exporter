ONTOS · Архив беседы 1.3.1

Сохраняет основную ветку открытой беседы, в том числе внутри проекта. Не использует прежнее внедрение скрипта через Edge.

Только chatgpt.com, без внешних серверов. Markdown/HTML содержат текст беседы, который тоже может быть конфиденциальным. Исходный JSON дополнительно содержит служебные записи и результаты инструментов. Никогда не публикуйте экспортированные данные без проверки. Прямой экспорт зависит от внутреннего интерфейса ChatGPT. Для гарантированного доступа к исходным данным используй официальный ZIP и ONTOS Reader.
