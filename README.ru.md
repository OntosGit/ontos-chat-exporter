# ONTOS Chat Exporter · инструкция

Экспорт **одной выбранной беседы ChatGPT** в Markdown, HTML или исходный JSON без ручной прокрутки. Работает с обычными разговорами и разговорами внутри проектов ChatGPT.

Это независимый экспериментальный инструмент, версия **1.3.1**. Проверен на реальной выгрузке 30 октября 2026 года и на синтетических тестовых данных. Не является официальным продуктом OpenAI. Внутренние интерфейсы ChatGPT могут измениться.

## Установка в Edge

1. На GitHub нажми **Code → Download ZIP**, распакуй архив в постоянную папку.
2. Открой `edge://extensions`, включи **Режим разработчика**.
3. Нажми **Загрузить распакованное** и выбери **папку `extension`**, внутри которой находится `manifest.json`.
4. Открой нужную беседу ChatGPT и обнови страницу (`Ctrl+R`).
5. Нажми значок расширения. Для переноса в другой чат удобнее **«Скачать диалог в Markdown»**; для чтения офлайн выбери HTML; для технического архива выбери JSON.
6. Скачанный файл найдёшь через `Ctrl+J`.

## Как оно работает

Экспортёр получает идентификатор беседы из **активной вкладки текущего окна Edge**. Остальные открытые вкладки в экспорт не попадают. Запрос выполняется к самому ChatGPT в твоём авторизованном сеансе. Приложение обрабатывает данные локально и сохраняет файл, без отправки стороннему серверу.

`Ctrl+S` может сохранить лишь часть длинного диалога из-за динамической подгрузки сообщений. Экспортёр читает исходные данные беседы и проверяет, что сервер указал конец постраничной истории. Это более надёжный способ, хотя абсолютной гарантии полноты серверных данных нет.

## Различия форматов

- **Markdown:** текст видимых сообщений основной ветки, удобно прикладывать к следующему разговору.
- **HTML:** те же извлечённые сообщения в статичной странице, без виртуальной прокрутки.
- **JSON:** сырой ответ ChatGPT, включая технические узлы и результаты инструментов. Может содержать очень чувствительные сведения. Храни приватно.

Медиафайлы, прикреплённые изображения, голосовые записи и озвучивание ответов **не записываются**. Для них потребуется отдельная функция или инструмент.

## Если появляется ошибка

- **`Blocked` / нет связи:** проверь общую настройку Edge «разрешать расширения на этом сайте» для `chatgpt.com`, затем обнови вкладку. Этот запрет может существовать даже при включённом расширении.
- **HTTP 500 / 403:** источник ChatGPT недоступен или изменился; это ограничение прямой выгрузки, а не требование заново устанавливать расширение.
- **Нет адреса /c/...:** сначала открой конкретный разговор.

## Автономный просмотрщик

Файл [`reader/ONTOS_Reader.html`](reader/ONTOS_Reader.html) открывается обычным двойным кликом. Он читает локальный JSON одной беседы или официальный ZIP-экспорт ChatGPT, позволяет выбрать разговор и сохранить Markdown/HTML. Никаких внешних серверов.

## Безопасность

Публикуй **код**, а не свои экспортированные беседы. В тестах используются только вымышленные сообщения. Исходный JSON может включать содержимое инструментов, ссылки и служебную информацию. Ни один экспортированный личный файл не должен попадать в публичный репозиторий или issue.

Исходный код можно проверить самостоятельно: [`extension/`](extension/). Разрешения расширения: активная вкладка и доступ к `chatgpt.com`. Сторонняя аналитика, микрофон и запись звука отсутствуют.

Тесты запускаются командой `node --test tests/*.test.cjs` (Node.js 20+). Сборка не нужна.

## Археология незавершённых архитектур · пилот

Добавлен [локальный инструмент ONTOS Memory](docs/ARCHITECTURE-MEMORY.md): импорт приватного архива ChatGPT в SQLite, полнотекстовый поиск, кандидаты на архитектуры из реплик пользователя и проверяемые связи с первоисточниками. Без облачного переноса разговоров, платного API или автоматического создания Todoist-задач. Запуск: `py -3 tools/ontos_memory.py --help`.
